==================================================

Endpoint da API:
https://api.rainviewer.com/public/weather-maps.json

A API retorna:
- host
- radar.past
- path
- timestamp

Construir o tile dinamicamente usando host + path retornados pela API.

Formato do tile:
{host}{path}/256/{z}/{x}/{y}/2/1_0.png

Não usar URLs antigas fixas.

Não inventar nowcast.

Não usar produto de satélite do RainViewer.

Colocar a atribuição:

5. MAPA DE INTENSIDADE SEM BOLINHAS
==================================================

Criar uma camada visual contínua de intensidade de chuva.

Não usar marcadores circulares.

Não mostrar somente 7 pontos.

Usar os valores das 7 estações para calcular uma superfície interpolada.

Preferencialmente usar IDW (Inverse Distance Weighting) para a interpolação inicial.

A superfície deve ficar limitada à área de interesse do aplicativo.

As cores devem representar intensidade:

0 mm/h:
transparente

0.1 - 2 mm/h:
azul claro

2 - 10 mm/h:
verde

10 - 30 mm/h:
amarelo

30 - 50 mm/h:
laranja

50 - 80 mm/h:
vermelho

>80 mm/h:
roxo

Não afirmar que a interpolação é uma medição real.

Mostrar na legenda:

"Estimativa interpolada entre estações CEMADEN"
